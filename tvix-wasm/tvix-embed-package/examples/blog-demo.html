Functions and Let Expressions

Nix supports functional programming concepts. Here's a more complex example:

Example 3: Functions and let expressions
let mkGreeting = name: "Hello, ${name}!"; users = [ "Alice" "Bob" "Charlie" ]; greetings = map mkGreeting users; in { message = mkGreeting "World"; allGreetings = greetings; count = builtins.length users; }

How to Use in Your Blog

To embed these evaluators in your own blog posts, include the component files and use the custom HTML tags:

<!-- Include the required scripts -->
<script src="codemirror-bundle.js"></script>
<script type="module" src="nix-component.js"></script>

<!-- Basic usage -->
<nix-evaluator expression="1 + 2"></nix-evaluator>

<!-- Advanced configuration -->
<nix-evaluator 
    height="300px"
    strict="true"
    live-mode="false" 
    raw-mode="true"
    show-controls="true">
{ myExpr = { a.b.c = 123; }; }
</nix-evaluator>

<!-- Content can also be in the tag body -->
<nix-evaluator height="200px">
let
  x = 42;
in
x * 2
</nix-evaluator>

Available Attributes

  • expression - Initial expression to load
  • height - Component height (default: 400px)
  • live-mode - Auto-evaluate on changes (default: true)
  • raw-mode - Show raw output without type annotations
  • strict - Enable strict evaluation mode
  • nix-compat - Enable Nix compatibility mode
  • show-controls - Show/hide control panel (default: true)
  • read-only - Make editor read-only (default: false)
  • save-changes - Emit change events (default: true)

Each component operates independently and can be configured with different settings. Try experimenting with the examples above!
